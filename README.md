# Trading Journal Pro V3.4 — Initial Balance BugFix

در V3.3 هندلر مدیریت سرمایه قبل از هندلر ثبت سرمایه اولیه قرار گرفته بود.
بنابراین عددی که کاربر بعد از /start وارد می‌کرد توسط هندلر مدیریت سرمایه گرفته می‌شد
و چون حالت capital_type فعال نبود، هیچ کاری انجام نمی‌شد.

در V3.4 ترتیب هندلرها اصلاح شده:
- عدد سرمایه اولیه بعد از /start → setup_balance
- افزایش/کاهش سرمایه از منوی مدیریت سرمایه → capital_adjustment
