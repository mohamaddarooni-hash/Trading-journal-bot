# Trading Journal Pro v3

این نسخه بر پایه bot.py اصلی پروژه ساخته شده و اصلاحات جمع‌بندی‌شده را اعمال می‌کند.

## اصلاحات اصلی
- نمادهای XAUUSD / NAS100 / US30 با باکس + نماد دیگر
- BUY / SELL با باکس
- سرمایه اولیه/مارجین یک‌بار و محاسبه خودکار سرمایه فعلی
- حذف دلیل ورود و احساس
- حجم انتخابی 0.01 تا 0.10
- چک‌لیست ۶ مرحله‌ای با متن‌های جدید
- نتیجه WIN / LOSS / BE به‌صورت انتخابی
- خروج واقعی دوباره گرفته می‌شود
- P/L و R:R خودکار
- Final Move و Missed Profit
- عکس با دو گزینه «آپلود عکس / عکس ندارم»
- گزارش‌های WIN/Loss/Win Rate/Profit Factor
- Drawdown از موجودی‌ها محاسبه و در معامله ثبت می‌شود
- تحلیل چک‌لیست به تفکیک WIN و LOSS
- هشدار افت روزانه بر اساس سرمایه شروع همان روز:
  0.5% گزارش، 1% استراحت، 1.5% کنترل احساسات، 2% توقف معامله
- تلاش شده migration غیرمخرب باشد و ستون‌های جدید به trades موجود اضافه شوند.

ضرایب حساب:
XAUUSD: 0.01 lot → هر $1 حرکت = $1
NAS100: 0.01 lot → هر 100 واحد = $1
US30: 0.01 lot → هر 100 واحد = $1
