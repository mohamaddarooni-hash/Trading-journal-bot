# Trading Journal Pro v2

این نسخه مستقیماً بر اساس bot.py اصلی پروژه ساخته شده و جریان ثبت معامله را به‌روزرسانی می‌کند.

## تغییرات
- XAUUSD / NAS100 / US30 + نماد دیگر
- BUY / SELL با دکمه
- سرمایه اولیه یک‌بار
- محاسبه سرمایه فعلی بعد از هر معامله
- ۶ مرحله چک‌لیست با تیک
- WIN / LOSS / BE
- ثبت خروج واقعی
- محاسبه خودکار P/L و R:R
- Final Move و Missed Profit
- Screenshot همراه گزارش همان معامله
- داشبورد، گزارش روزانه/هفتگی/ماهانه
- Drawdown، رکوردها و تحلیل نماد
- ظاهر خلوت با ایموجی‌های محدود

## ضرایب حساب
- XAUUSD: 0.01 lot → هر $1 حرکت = $1
- NAS100: 0.01 lot → هر 100 واحد حرکت = $1
- US30: 0.01 lot → هر 100 واحد حرکت = $1
